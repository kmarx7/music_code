## 1. 순서

```text
D-04 → P6-01 빠진 기능(커서 재생·구간 삭제·실시간 음높이)
     → P6-02 홈·시작 흐름 → P6-03 모바일 편집기 → P6-04 접근성
     → P6-05 오류·복구 → P6-06 개인정보·약관·라이선스 → P6-07 보안 헤더
     → P6-08 실제 허밍 평가 도구 (사용자 녹음은 병행 가능)
     → P6-09 배포 연동·베타 후보 배포 → P6-10 전체 수동 회귀 → P6-11 결함 수정 → P6-12 MVP 인수 보고서
```

P6-01~08은 로컬에서 끝난다. P6-09부터는 push·배포·실기기가 필요하며 각각 사용자 승인 대상이다.

## 2. 작업

### D-04 — Phase 6 정책 확정 — Done (2026-11-14 권고안 그대로 승인)
- 마스터 플랜 §4의 결정 1~12. 결정 2(녹음 화면)는 PRD §4 수정을 포함한다.

### P6-01 — PRD 빠진 기능 (결정 1) — Done
- 커서부터 재생: 편집 커서가 있으면 그 tick부터, 연습 속도·A–B 반복·메트로놈과 함께. 커서가 없으면 처음부터.
- 선택 구간 삭제: 기존 연속 선택과 Cut의 정책(타이 체인 보호)을 재사용, 단일 Command·1회 Undo, clipboard는 바꾸지 않는다.
- 실시간 추정 음높이: 녹음 중 최근 프레임의 음이름·센트 표시(기존 `estimatePitchTrack` 재사용, 화면 갱신 상한 유지). 후보·저장에는 영향 없음.
- 수용: 각 기능 단위·E2E, 기존 재생·클립보드·녹음 테스트 무변경 통과.

- 수용: 첫 방문(악보 없음)·악보 있음 두 상태 E2E, 새 악보가 한 번만 만들어진다.
