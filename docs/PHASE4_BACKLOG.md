### P4-02 — 음높이 추정

- 진행 상태(2026-11-13): **완료.** 상세·수치는 TASKS §23. FFT·11kHz 최적화 후 96초 입력 M2 Node 약 0.6초, 메인 스레드 유지(결정 2).
- 범위: Domain 순수 함수. PCM → 프레임별 `{ 주파수, 신뢰도 }`, 무음/무성 판별, 평활화, 옥타브 튐 보정.
- 수용: 합성 fixture에서 프레임 음높이 오차와 옥타브 오류율을 기록한다. 무음·잡음만 있는 입력에서 음을 만들지 않는다.
  상한 8마디 입력의 분석 시간을 측정해 기록한다. 최소 4/4 60 BPM(32초)과 20 BPM(96초)을 포함한다(결정 2·4 재검토 근거).
  현재 합성 사례는 2–4마디뿐이므로 8마디 사례를 추가해 측정한다.
- 경계: 새 의존성 없음(결정 1). Worker 없음(결정 2).

### P4-03 — 음 분할

- 진행 상태(2026-11-13): **완료.** 상세·수치는 TASKS §24. 합성 40사례 370/370음 일치, 시작 오차 중앙값 8ms.
- 범위: 프레임 열 → 음 구간(시작·끝·대표 음높이·신뢰도). 같은 음 반복 분리, 너무 짧은 조각 제거, 쉼표 구간.
- 수용: 반복음·쉼표·도약·비브라토 fixture에서 음 수와 경계 오차를 기록한다.

### P4-04 — 격자 맞춤과 후보 변환

- 진행 상태(2026-11-13): **완료.** 상세는 TASKS §25. 16분음표 격자 맞춤(표기 불가 길이 없음), 후보는 `ClipboardPayload`.
  합성 40사례 전체 흐름 note F1 1.000, 붙여넣기·검증 실패 0.
- 범위: 초 단위 구간 → 빠르기·박자 기준 tick. 후보 음표/쉼표 목록. 마디 넘는 음은 기존 분할·타이 재사용.
  표기 불가 길이는 조용히 근사하지 않고 정책에 따라 거부하거나 가장 가까운 지원 길이로의 맞춤을 **명시적으로** 수행한다(세부는 착수 시 결정).
- 수용: 합성 fixture 전체의 note F1과 오류 분류를 기록한다. 후보는 `validateScore`를 통과하는 이벤트로만 변환된다.

### P4-05 — 마이크 캡처 adapter와 포트

- 선행 권고: Phase 3 수동 UAT-S/UAT-A. → 2026-11-13 사용자 결정으로 수동 UAT는 모든 작업 후 마지막에 수행한다.
- 진행 상태(2026-11-13): **완료(가짜 장치로 자동 검증).** 상세는 TASKS §26. 실제 브라우저·마이크에서는 아직 실행하지 않았다.
- 범위: `AudioTranscriptionPort` 계약, AudioWorklet PCM 수집, 권한 거부·장치 없음·연결 끊김·무음·중단 처리, 8마디 상한(설정 템포·박자로 계산한 길이에서 자동 정지, 카운트인 제외).
- 수용: 가짜 입력으로 시작/정지/오류 경로가 테스트된다. 캡처 종료 후 트랙·오디오 자원이 해제된다.
  PCM은 메모리에만 있고 네트워크·저장소 쓰기가 없다.

### P4-06 — 녹음 UI

- 범위: 동의 문구, 시작/정지, 경과 시간, 입력 레벨, 빠르기·박자·메트로놈 선택, 상태·오류 안내. 실시간 음높이는 없음(결정 3).
- 수용: 권한 거부·무음·오류 후에도 기존 악보 편집·저장이 계속된다. UI 변경이므로 전체 E2E.

### P4-07 — 후보 검토와 원자 확정

- 범위: 후보 미리보기, 낮은 신뢰도 표시, 확정/취소. 확정은 Command 1개, 붙여넣기와 같은 빈 대상 규칙(결정 5), 기존 자동 저장.
- 수용: 취소·실패는 Score/이력/저장 무변경. 확정 후 Undo 1회로 전부 복원. 저장·재열기·JSON에 후보·녹음·설정이 남지 않는다.

### P4-08 — 통합 인수

- 범위: 녹음→분석→검토→확정→편집→저장→재열기 흐름 E2E(가짜 마이크), 품질 수치 정리, 수동 UAT 절차.
- 수용: 4–8마디 통제된 선율이 편집·저장 가능한 음표가 된다(PRD MVP-003 Acceptance).
  실제 허밍·Safari·실기기 결과를 별도로 기록한다. 미실행은 NOT RUN.
