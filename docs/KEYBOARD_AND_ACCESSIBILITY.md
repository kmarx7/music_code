# 키보드 배치와 접근성 대체 경로

- 작성: 2026-11-14(P6-04). 근거: PRD MVP-001 "키보드 배치와 접근성 대체 경로 문서화", PRD §5 접근성, D-04 결정 5(WCAG 2.2 AA).
- 자동 검사: `tests/e2e/a11y.spec.ts`(axe, 홈·악보함·편집기·조옮김·인쇄·모바일 탭 4개, 모든 위반 0건), `tests/e2e/keyboard-journey.spec.ts`(Tab만으로 주요 흐름).

## 1. 컴퓨터 키보드 건반

편집기에서 글자 입력란·선택 상자에 포커스가 없을 때 아래 키가 음을 넣는다(현재 길이, 입력 위치 규칙 그대로).

| 키 | A | W | S | E | D | F | T | G | Y | H | U | J |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 음 | C | C♯ | D | D♯ | E | F | F♯ | G | G♯ | A | A♯ | B |

- 옥타브는 4(가운데 도 C4~B4)로 고정이다. 다른 옥타브는 화면 건반이나 선택 후 "반음 올리기/내리기"로 넣는다(옥타브 전환 키는 MVP에 없음).
- Ctrl·⌘·Alt 조합과 키를 누르고 있을 때의 반복 입력은 무시한다.

## 2. 마우스·터치 없이 하는 대체 경로

| 작업 | 포인터 방식 | 키보드·보조기기 경로 |
|---|---|---|
| 음표 선택 | 악보의 음표를 누름 | "음표·쉼표 목록"의 버튼(음 이름, 붙임줄은 ⌒) |
| 음높이·길이 수정 | — | 목록에서 선택 → "반음 올리기/내리기", 길이 버튼 |
| 입력 위치 | — | "입력 위치" 선택 → "커서 마디/커서 박" 입력 → "커서 이동" |
| 구간 선택 | — | "구간 첫/마지막 마디" 입력 → "구간 선택" |
| 악보 보기(넓은 악보) | 가로 스크롤 | 악보 영역(이름 "악보")에 Tab으로 포커스 후 화살표 키 |
| 연습 속도 | 슬라이더 끌기 | 슬라이더에서 ←/→(5%씩), 프리셋 버튼 |
| 재생 | Play | Tab으로 Play → Enter. 재생 중에는 같은 버튼이 Stop이 된다 |
| 휴대폰 화면 영역 | 탭 누르기 | "편집기 영역" 탭 목록(입력 / 재생·연습 / 편집 / 파일) |

## 3. 상태 알림

- 저장 상태(저장 중·저장됨·실패·충돌), 편집 오류, 클립보드·녹음·출력 결과는 화면 문구와 `role="status"`/`role="alert"`로 알린다.
- 녹음 중 실시간 음높이는 매우 자주 바뀌므로 스크린리더가 읽지 않게 했다(`aria-live="off"`). 녹음 진행은 상태 문구로 알린다.

## 4. 알려진 제한

- 악보(SVG) 자체는 그림이다. 음표 정보는 "음표·쉼표 목록"과 요약 줄로 제공한다. 악보를 음성으로 읽어 주는 기능은 MVP 밖이다.
- 피아노 건반은 88개 버튼이라 Tab으로 지나가려면 많이 눌러야 한다. 입력은 컴퓨터 키보드 배치를 권장한다.
- 기본 `<select>` 목록 안의 키보드 선택은 브라우저가 제공하며, 헤드리스 자동 검사로는 확인할 수 없어 수동 UAT-K로 확인한다.
- VoiceOver(맥·iPhone) 실제 사용성은 수동 UAT-K 전까지 NOT RUN.
