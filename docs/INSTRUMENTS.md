# 국악기 기준값 (Phase 7 B-1, 결정 5)

상태: **확인 전.** 아래 "조사값"은 공개 자료에서 찾은 후보일 뿐이며 앱에 넣지 않는다.
전문가(연주자·전공자·교재)가 "확인값" 칸을 채우고 확인자·일자를 적은 뒤에만
`src/domain/score/instruments.ts`의 프로필 값과 `verified: true`로 옮긴다.
옮긴 뒤 B-3(악기에 맞추기)~B-6을 진행한다.

표기: 음높이는 과학적 음높이(가온 도 = C4 = MIDI 60). 국악 율명이 편하면 율명과 옥타브(배·중·청)로 적어도 된다.
