작성: 2026-11-13, Claude Code. 대상 코드: 처음 `9a8b3dc`. 2026-11-14 P6-10용 갱신: 공개 주소는 GitHub main과 연동되어
자동 배포된다(베타 후보 `0a2fcfd` 이후). 실행 전 화면 하단이 아니라 Vercel 배포 목록·`git log`로 배포 커밋을 확인해 기록한다.

이 문서는 사람이 직접 실행하는 인수 점검표다. 항목의 원문 계약은
[PHASE2_ACCEPTANCE_REPORT §7](PHASE2_ACCEPTANCE_REPORT.md)(M/A/T)과
[PHASE3_BACKLOG](PHASE3_BACKLOG.md)의 UAT 표이며, 이 문서는 그것을 실행 순서대로 풀어 쓴 것이다.
두 문서와 다르면 원문이 우선한다.

**모든 항목의 현재 상태는 NOT RUN이다.** Chromium·WebKit 자동 테스트 통과를 수동 PASS로 옮겨 적지 않는다.
PASS는 실행자·일시·증거 위치가 있을 때만 기록한다.

## 2. UAT-A — 실제 청취

기록: 스피커/헤드폰, 볼륨, 튜너(앱) 종류, 기준 튜닝. 녹취는 합성음만.

- [ ] A-01 음높이: C4와 A4(440Hz)를 튜너와 비교한다. 입력 미리듣기와 전체 재생을 각각 확인한다.
      B#3와 C4는 소리가 같고 라벨만 다르다.
- [ ] A-02 조옮김: C→D/Db/C# 확정 전후로 같은 선율을 듣고 Undo/Redo 후 다시 재생한다.
      반음 이동량이 소리와 일치한다. Db와 C#은 소리가 같고 철자만 다르다.
- [ ] A-03 타이: 줄을 넘는 타이를 재생하고 중간에 일시정지·재개·정지한다.
      경계에서 음이 다시 울리지 않고, 재개 시 남은 길이만 한 번 울리고, 정지 후 잔음이 없다.
- [ ] A-04 메트로놈: 2/4·3/4·4/4·6/8, 60/120BPM, 메트로놈 켬/끔. 첫 박 강조와 클릭·음표 정렬이 맞다.
- [ ] A-05 오류 복구: 입력음 켬/끔, 빠른 반복, 탭 숨김, 시스템 음소거 후 해제.
      음표 입력과 저장은 계속되고 이전 음이 남거나 두 번 울리지 않는다. OS 음소거는 앱 오류와 구분해 적는다.

연습 속도·A–B 반복(Phase 3 추가분):

- [ ] A-R1 속도를 바꿔 재생하면 음높이는 그대로이고 빠르기만 바뀐다. 메트로놈도 함께 맞는다.
- [ ] A-R2 재생 중 속도를 바꿔도 끊김·겹침·잔음이 없다.
- [ ] A-L1 A–B 구간 끝에서 처음으로 돌아갈 때 마지막 음이 잘리지 않고 첫 음이 두 번 울리지 않는다.
- [ ] A-L2 반복 중 일시정지·재개·정지, 탭 숨김 후 복귀가 정상이다.
- [ ] A-L3 속도·반복을 설정한 뒤 저장하고 다시 열거나 JSON을 받아도 그 설정은 악보에 저장되어 있지 않다.

틀린 음은 `마디·박 / 예상 음 / 실제 들린 음`으로 적는다.

## 6A. P6-10 권장 실행 순서 (기기가 모자랄 때)

모든 기기를 갖추기 어려우면 아래 순서로 실행하고, 못 한 기기는 NOT RUN으로 남긴다(PASS로 추정하지 않는다).

1. Mac Chrome: UAT-C, UAT-B, UAT-P, UAT-I, UAT-U, UAT-X, UAT-K(K-01·K-02·K-05)
2. iPhone Safari: UAT-T, UAT-B(B-01·B-04~B-06), UAT-P(P-04·P-05), UAT-I(I-02·I-05·I-09), UAT-H, UAT-X(X-09), UAT-K(K-04)
3. Mac Safari: UAT-S, UAT-B(B-09), UAT-U, UAT-K(K-03)
4. 실제 청취: UAT-A (Mac 스피커·이어폰 한 번씩)
4-1. 연주자: UAT-G (Mac Chrome에서 만든 PDF·MusicXML로)
5. Android Chrome: UAT-T, UAT-B(B-04~B-06), UAT-H
6. UAT-R 이탈·강제 종료

결정 11의 출시 기준: 실행한 모든 항목에서 P0/P1 결함 0건. P2는 목록으로 남기고 출시 여부를 사용자와 정한다.

## 7. 이 점검으로 확인되지 않는 것

- Firefox는 대상에 없다.
- 출력 자동 검사는 Chromium `page.pdf()`·공식 XSD·테스트용 MIDI 파서까지다. 외부 악보 프로그램 호환성과 실제 인쇄는 UAT-X에서만 확인된다.
- 자동 테스트의 녹음 입력은 Chromium 가짜 장치와 페이지에서 만든 일정음이다. 실제 목소리 채보 품질은 UAT-H에서만 측정된다.
- 대형 악보 성능(H-03)은 Apple M2·Chromium 합성 측정으로만 닫았다. Safari·실기기 성능은 이 점검표의 통과 기준이 아니다.
- 공개 주소는 2026-11-14부터 GitHub main 연동으로 자동 갱신된다. 실행 도중 배포가 바뀌면 기록한 커밋과 달라질 수 있으니 실행 전후 배포 커밋을 확인한다.
